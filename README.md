# 街道智慧街区 · 平台宣传官网

太原抱鼓巷「街道智慧治理与运营一体化平台」的宣传门户（静态单页）。
延续平台「青砖黛瓦 × 鎏金牌匾」品牌：青黛蓝、古铜金、衬线宋体、金线圆章「晋」。

## 在线访问

GitHub Pages 地址：`https://<你的用户名>.github.io/<仓库名>/`

## 本地预览

```bash
node server.js
# 打开 http://localhost:3003/portal/
```

或任意静态服务器指向本目录均可。无任何构建依赖。

## 页面结构

- Hero：抱鼓巷实景 + 「让七百米老街长出数字化的翅膀」+ 向下浏览提示
- 一横三端：H5 移动门户（含 AI 管家/移动工作台）/ Web 运营管理端 / 可视化数据大屏
- **产品一览**（PRODUCT TOUR）：四端真实界面——管理端浏览器窗、H5 双机（首页/工作台）、金边数据大屏
- 核心能力：智慧治理 / 商户赋能 / 游客服务 / 数字中枢
- **AI 智能层**：AI 管家「晋小二」——对话式办事、双引擎保障（大模型+规则兜底）、安全红线（预览卡确认制/紧急直转人工），含对话交互示意
- 街区背景：抱鼓巷（唐风晋韵、700 米夜经济步行街、5G+AR 数字街区）
- 体验入口：三端入口（自动探活，不可达时降级为本地启动指引）
- 页脚：品牌区 / 平台能力 / 关于街区 三列结构
